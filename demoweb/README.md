# Ảnh chụp giao diện demo — ladingpage-dvmxhv1

Ảnh chụp từ bản chạy thật của thư mục `ladingpage-dvmxhv1` (SUB24H.NET landing demo), để xem nhanh web khi chạy sẽ trông như thế nào mà không cần mở code.

## Desktop (1280px)

- `01-trang-chu-desktop.png` — Phần đầu trang (hero) + mô phỏng bảng điều khiển
- `02-nen-tang-desktop.png` — Mục các nền tảng hỗ trợ (Facebook, TikTok, Instagram, YouTube, Telegram, Shopee...)
- `03-giao-dien-quan-ly-desktop.png` — Mục mô phỏng giao diện quản lý hệ thống
- `04-bang-gia-desktop.png` — Bảng giá dịch vụ tham khảo
- `05-faq-desktop.png` — Câu hỏi thường gặp + banner đăng ký
- `06-toan-trang-desktop.png` — Toàn bộ trang trong một ảnh

## Mobile (390px)

- `01-trang-chu-mobile.png` — Giao diện đầu trang trên điện thoại

## Cách chạy thử

Mở file `ladingpage-dvmxhv1/index.html` trong trình duyệt, hoặc chạy server tĩnh tại thư mục đó, ví dụ: `python3 -m http.server`
