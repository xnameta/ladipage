# Ảnh chụp giao diện demo — ladipage-dvmxh

Ảnh chụp từ bản chạy thật của thư mục `ladipage-dvmxh` (SUB24H.NET — bản gốc), để xem nhanh web khi chạy sẽ trông như thế nào mà không cần mở code.

## Desktop (1280px)

- `01-trang-chu-desktop.png` — Phần đầu trang (hero) + biểu đồ Analytics Suite
- `02-dich-vu-desktop.png` — Mục dịch vụ theo nền tảng (Facebook, TikTok, Instagram, YouTube...)
- `03-uu-diem-desktop.png` — Ưu điểm nổi bật + quy trình 6 bước
- `04-bang-gia-desktop.png` — Công cụ ước tính chi phí + bảng giá dịch vụ
- `05-faq-desktop.png` — Câu hỏi thường gặp (FAQ)
- `06-toan-trang-desktop.png` — Toàn bộ trang trong một ảnh

## Mobile (390px)

- `01-trang-chu-mobile.png` — Giao diện đầu trang trên điện thoại

## Cách chạy thử

Mở file `ladipage-dvmxh/index.html` trong trình duyệt, hoặc chạy server tĩnh tại thư mục đó, ví dụ: `python3 -m http.server` (cần có mạng để tải thư viện từ CDN: Tailwind, Chart.js, Font Awesome).
